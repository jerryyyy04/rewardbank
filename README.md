\# RewardBank



RewardBank is a small API project for managing children's screen-time rewards.



A parent can create tasks and give screen-time minutes as rewards.

The child can then use those minutes for apps like YouTube or games.



\## Features



\- Parent and child token authentication

\- Create and complete tasks

\- Approve tasks and give reward minutes

\- Track screen-time usage

\- Prevent duplicate usage charges

\- Prevent double task approval

\- Handle insufficient balance

\- Undo task approval

\- Keep a complete ledger of balance changes



\## Tech Used



\- Python

\- FastAPI

\- SQLite

\- Pytest
